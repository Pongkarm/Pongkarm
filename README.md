### 👋 About Me

3rd-year **Computer Engineering** student at **Chitralada Technology Institute (CDTI)**, Bangkok. Focusing on embedded systems, computer architecture, and low-level software development.

- ⚡ **Embedded Systems & Microcontrollers:** Deep diving into AVR ATmega architecture, registers, timers/counters, and hardware interrupts in C and Assembly.
- 💻 **Systems & Software Development:** Exploring computer architecture and operating system internals, building structured applications with C/C++, C#, and Python.
- 🤖 **Robotics & Hardware:** Background in vocational robotics, RC vehicles, logic circuits, and educational robotics.
